# Sistema de Gestão para Sapataria - Projeto Final

Este repositório contém a entrega do projeto final desenvolvido em equipe para o componente curricular. Trata-se de um sistema web em PHP estruturado com Programação Orientada a Objetos (POO) para automatizar e otimizar os processos de controle de uma sapataria.

## 🎯 2. Situação-Problema
Muitas sapatarias de médio e pequeno porte enfrentam dificuldades no controlo manual de stock, registo de clientes, gestão de funcionários e acompanhamento de vendas diárias. Isso gera erros humanos, perdas de produtos e falta de agilidade no atendimento.

## 🚀 3. Objetivo
Desenvolver um sistema web eficiente e modular para centralizar o controlo de stock, o cadastro de clientes, o registo de funcionários, a gestão de produtos e o processamento de vendas, garantindo organização, integridade de dados e facilidade de uso.

## ⚙️ 4. Principais Funcionalidades
 **Gestão de Produtos:** Controlo do catálogo de calçados, tamanhos, marcas e preços.
 **Controlo de Stock:** Atualização automática de quantidades disponíveis e alertas de reposição.
 **Registo de Clientes:** Gestão de cadastros com histórico de interações e compras.
 **Gestão de Funcionários:** Controlo de acessos, cargos e dados da equipa.
 **Processamento de Vendas:** Registo ágil de transações vinculando produtos, funcionários e clientes.

## 💻 5. Tecnologias Utilizadas
 **Linguagem:** PHP (Orientado a Objetos)
 **Controlo de Versões:** Git e GitHub,
 **Servidor Local:** XAMPP (Apache)
**Documentação:** PDF (`docs/Documentacao_Tecnica.pdf`)
